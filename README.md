Pocket Hamster — a one-sentence absurd invention pitch for the [make.fun bounty](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a). The program writes a single sentence to `entry.txt`: a pocket treadmill charger that only powers your dying phone while you pace anxiously, turning every 1% panic into honest electricity. `main.ts` checks the pitch against the gate first (UTF-8 text, 1 to 220 characters, not only whitespace, exactly one sentence ending in a period) and then verifies the written file round-trips byte-identically; it is fully deterministic and writes nowhere except the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/output node main.ts
```
